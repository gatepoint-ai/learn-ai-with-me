# Resources — free courses and official documentation

*Every link below was checked and opened on 14 Oct 2026. If one breaks, please open an issue.*

## Courses — foundations

| Resource | From | Why I recommend it |
|---|---|---|
| [MIT 6.S191 — Introduction to Deep Learning](https://introtodeeplearning.com/) | MIT | Short, current, free lectures and labs. The best fast start on how modern AI works. |
| [Introduction to Machine Learning (6.036)](https://ocw.mit.edu/courses/6-036-introduction-to-machine-learning-fall-2020/) | MIT OpenCourseWare | Solid grounding in supervised vs unsupervised learning, evaluation and overfitting. |
| [CS25: Transformers United](https://web.stanford.edu/class/cs25/) | Stanford | Talks from researchers building today's language models. |
| [Practical Deep Learning for Coders](https://course.fast.ai/) | fast.ai | Hands-on, code-first; good if you want to build something quickly. |
| [Neural Networks: Zero to Hero](https://karpathy.ai/zero-to-hero.html) | Andrej Karpathy | Builds a language model from scratch, step by step. Deep, but unusually clear. |
| [Hugging Face Learn](https://huggingface.co/learn) | Hugging Face | Free courses on language models, agents and open-source AI tools. |
